Sobre o Projeto SENAI-ALUNOS

Quem Somos

Este site foi desenvolvido pelos alunos do SENAI com o objetivo de facilitar o acesso a informações importantes, como carteirinha de estudante, área do perfil, links úteis e muito mais.

Nosso objetivo principal foi criar um site funcional, claro e acessível, demonstrando as habilidades adquiridas ao longo do curso.

O projeto utilizou tecnologias como HTML, CSS, JavaScript, Git e GitHub, permitindo criar um site moderno e alinhado às boas práticas.
