Projeto SENAI Alunos – Sistema de Carteirinha do Aluno

Projeto desenvolvido no SENAI como parte da avaliação do curso de Programação Full Stack, com foco em desenvolvimento web.


Tecnologias:

- HTML5
- CSS3
- JavaScript
- Python

Funcionalidades:

- Home
- Sobre
- Cadastro
- Login
- Carteirinha digital do aluno
- QR Code único por aluno
  

Design:

- Paleta de cores oficial do SENAI

- Interface simples e organizada
  

Contexto:

Projeto criado para avaliar o desempenho prático do aluno, simulando um sistema real utilizado por instituições de ensino.


Status: Projeto finalizado.
